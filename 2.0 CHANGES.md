  - `fluid_level_spread`
  - `lava`
  - `vein_toggle`
  - `vein_ridged`
  - `vein_gap`

- `axis` density function
- `ceil` density function
- `floor` density function
- `mix` density function
- `select` density function
- `sqrt` density function
